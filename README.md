# Smart Parking Lot System

## Problem Statement
Design a backend system for managing a smart parking lot with multiple floors, spot allocation, and fee calculation.

## Features
- Automatic parking spot allocation by vehicle type
- Multiple floors with configurable parking spots
- Entry and exit time tracking
- Parking fee calculation based on duration
- Real-time availability tracking (EXTRA)

## Design
- Object-Oriented Low-Level Design
- UML Class Diagram available in /docs
- Design decisions documented separately

## How to Run
1. Compile and run Main.java
2. Use console menu for vehicle entry/exit
